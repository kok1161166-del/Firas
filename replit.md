# Firas Stream Hub

## Run locally on Replit

- Install dependencies with the project package manager.
- Start the Vite preview with `npm run dev -- --port 5000`.
- The Replit workflow is named `Start application` and serves the app on port `5000`.

## Notes

- The app is a React + TypeScript + Vite site.
- The live status, social counters, and AI features depend on external services and may show fallback states when those services reject requests or are unavailable.
